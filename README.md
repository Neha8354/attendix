# attendix

Student Attendance Utility

Attendix is an attendance planner and simulator designed to help students track their attendance and predict future outcomes. It simplifies attendance calculations and provides clear insights into eligibility based on minimum attendance criteria.

Features • Attendance percentage calculation • Minimum attendance requirement check (e.g., 75%) • Future attendance simulation • Calculation of required classes to regain eligibility • Simple and minimal interface

How It Works 1. Enter total classes conducted. 2. Enter classes attended. 3. The app calculates the current attendance percentage. 4. Set a minimum required attendance threshold. 5. Simulate attending or missing upcoming classes to see how your percentage changes. 6. The app indicates whether you meet the requirement and how many classes you must attend to stay eligible.

Purpose

The goal of Attendix is to eliminate manual calculations and reduce last-minute uncertainty. It demonstrates practical problem-solving through accurate percentage computation and predictive simulation logic.
